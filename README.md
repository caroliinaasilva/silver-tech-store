# Silver Tech

Silver Tech is a website prototype designed to provide friendly technology support for seniors in Dublin.

## Features

- Home page
- Services page
- About page
- Contact form with validation
- Shop page
- Basket page
- Checkout page
- Product data loaded from MySQL

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL
- Docker

## Installation

Install dependencies:

```bash
npm install
```

Start server:

```bash
node server.js
```

Open in browser:

```text
http://localhost:3000
```

## Database

Create database:

```sql
CREATE DATABASE silvertech;
```

Import the products table and run the application.
